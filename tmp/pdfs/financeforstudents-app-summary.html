FinanceForStudents: App Summary

Repo-based summary (HTML/CSS/JS evidence only)

What It Is

FinanceForStudents is a static, multi-page educational web app for business and finance learning. It combines guided lessons, quizzes, workshop scheduling, a dashboard, a stock simulator, and an in-page finance chatbot.

Who It Is For

Primary persona: students (especially finance/business learners) who want peer-oriented, self-paced practice with tutoring/workshop support.

Evidence: home page messaging "created by students, for students" and education-focused lesson flows.

What It Does

  • Provides six structured lessons with step flow: Content - Activity - Video - Quiz.
  • Tracks lesson completion and quiz averages in client-side storage (`localStorage`).
  • Shows dashboard progress, streaks, badges, and next-lesson recommendations.
  • Offers schedule/calendar views with RSVP plus custom user-created study events.
  • Includes a stock market simulator with virtual $10,000, buy/sell trades, and charted portfolio history.
  • Supplies downloadable study materials (generated browser downloads: HTML/CSV).
  • Embeds a finance chatbot: Gemini API attempt plus rule-based fallback.

How It Works (Compact Architecture)

Frontend: Standalone HTML pages (`index`, `resources`, `schedule`, `dashboard`, `stock-game`, `profile`, lesson pages) share CSS layers and load page-specific JS IIFEs.

Shared modules/services: `js/app.js` (nav state), `js/lessons.js` (lesson config + progress API), `js/chatbot.js`, `js/calendar.js`, `js/stock-game.js`, `js/lesson-steps.js`, `js/downloads.js`, `js/quizzes.js`.

Data flow: User actions in forms/buttons -> JS handlers update DOM and (where implemented) `localStorage` keys (`financeForStudents_lessonProgress`, `financeForStudents_quizScores`, `ffs-rsvps`, `ffs-custom-events`) -> pages recompute progress/UI on load.

External calls/deps: Chart.js via CDN for stock chart; chatbot `fetch` to Gemini endpoint with in-browser fallback responses on failure.

Backend/API auth server: Not found in repo.
Persistent database/multi-user account system: Not found in repo.

How To Run (Minimal)

  1. Open index.html directly in a browser.
  2. Or serve locally from repo root: python -m http.server 8000.
  3. Visit http://localhost:8000/index.html.

No package manager, build step, or bundler is required in repo evidence.
